# 🍳 Fridge to Recipe

Fridge to Recipe is an AI-powered recipe generator that helps users turn the ingredients they already have into a practical and delicious recipe.

Instead of wondering what to cook, users can select ingredients from an interactive checklist, add custom ingredients, choose meal and dietary preferences, and generate a recipe using AI.

## ✨ Features

- 🥕 Interactive ingredient checklist
- ➕ Add custom ingredients using "Other ingredients"
- 🍽️ Meal type preferences
- 🌱 Dietary preferences
- ⏱️ Cooking-time preferences
- ✨ AI-generated recipes
- 👥 Adjustable serving sizes
- 🧮 Automatic ingredient quantity scaling
- 👩‍🍳 Interactive cooking-step checklist
- 🔄 Ingredient substitution suggestions
- 🎨 Responsive and animated UI
- 🌿 Soft, aesthetic recipe-focused design
